# الاختبارات

| الملف | ماذا يختبر | كيف يُشغَّل |
|---|---|---|
| `e2e.mjs` | دورة العمل كاملة (29 فحصًا): العداد، الاعتماد، المراجعة، النقل، التصفير، التقرير | `node e2e.mjs` |
| `custody.mjs` | العُهد وقطع الغيار (117 فحصًا): الرقم التسلسلي المكرر، التركيب على شاحنتين، الصرف بأمر صيانة أو سبب معتمد، مصير القطعة القديمة، تبديل السائق، التسليم والقبول، المخزون لا يصبح سالبًا، الصلاحيات وعزل الشركات، التقارير الـ14 وإكسل، السجل لا يُحذف | `node custody.mjs` |
| `concurrency.mjs` | تحميلان متزامنان على عداد واحد، و30 طلبًا في اللحظة نفسها | `node concurrency.mjs` |
| `security.mjs` | 117 هجومًا: الدخول، الرموز، الجلسات، الصلاحيات، عزل الشركات، الحقن، الملفات، قاعدة البيانات | `node security.mjs` |
| `web-security.mjs` | المتصفح: لا رموز قابلة للقراءة، XSS، CSP، الخروج | `node web-security.mjs` |
| `web-functional.mjs` | عمل المكتب من صفحات الويب: البيانات، المستخدم، الإسناد، الطلب، النقل، وما يراه السائق | `node web-functional.mjs` |
| `app-flow.mjs` + `mobile/test/live` | تطبيق السائق الحقيقي (الشاشات) ضد الخادم، ثم التحقق من النظام | انظر رأس الملف |
| `loading-docs.mjs` | «توثيق التعبئة»: يظهر السجل مع أول صورة تعبئة مرتبطًا برقم الطلب والرحلة، صورة ما بعد التعبئة في السجل نفسه، الحالات والأسباب، طلب إعادة التصوير (إشعار السائق وفتح الخانة وحدها بعد الإرسال وحفظ النسختين)، البحث والفلاتر والإجماليات وExcel، الصلاحيات وعزل الشركات | `node loading-docs.mjs` |
| `loading-docs-web.mjs` | صفحة «توثيق التعبئة» في المتصفح: الإجماليات كفلاتر، الصور جنبًا إلى جنب، التكبير، التنزيل، طلب إعادة التصوير | `PHOTO=… node loading-docs-web.mjs` (لوحة الويب مبنية داخل `wwwroot`) |
| `fill-app-flow.mjs loading` + `mobile/test/live/loading_docs_test.dart` | تطبيق السائق الحقيقي: صورة قبل التعبئة متصلًا، وبعد التعبئة دون اتصال ثم المزامنة، ثم إعادة التصوير بطلب المشرف على تقرير مُرسل، مع فحوص المكتب أثناء التشغيل | `PHOTO=… node fill-app-flow.mjs loading` |
| `loadtest.mjs` | الحمل: 100 سائق + 20 موظف، ثم 300 سائق | انظر رأس الملف (يتطلب رفع حدود كل IP مؤقتًا) |

- **عنوان الخادم:** المتغيّر `API`، مثل `https://staging.<نطاقك>`.
- **قاعدة جديدة:** شغّلها على قاعدة بيانات جديدة بالبيانات التجريبية، وبالترتيب أعلاه.
- **الانتظار:** دقيقة بين `security.mjs` وما بعده (حد محاولات الدخول).
