# إجابات نموذج سلامة البيانات (Google Play) وخصوصية التطبيق (App Store)

| السؤال | الإجابة |
|---|---|
| هل يجمع التطبيق بيانات؟ | نعم |
| هل تُشفّر أثناء النقل؟ | نعم (HTTPS إلزامي في نسخة المتجر) |
| هل يستطيع المستخدم طلب حذف بياناته؟ | نعم عبر جهة العمل؛ بعض سجلات العمليات تُحتفظ نظاميًا (اذكر ذلك) |
| المعلومات الشخصية | الاسم، رقم الهاتف، معرّف المستخدم — **وظائف التطبيق، إدارة الحساب** — غير مشاركة لأغراض إعلانية |
| الصور | صور يلتقطها المستخدم داخل التطبيق — **وظائف التطبيق** |
| الموقع | تقريبي/دقيق فقط إن فُعّل إرساله مع الصور أو التتبع — **وظائف التطبيق** |
| معرّفات الجهاز | لا (لا إعلانات ولا تحليلات) |
| بيانات التطبيق والأداء (سجلات الأعطال) | تُسجَّل في الخادم فقط، دون SDK طرف ثالث |
| التتبع عبر التطبيقات (iOS ATT) | لا |
| الجمهور المستهدف | بالغون (موظفو الشركة)، ليس للأطفال |
| الوصول المقيد | التطبيق يتطلب حسابًا من جهة العمل — قدّم للمراجعين حسابًا تجريبيًا على بيئة الاختبار |
